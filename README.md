# telecom-analysis
Análisis exploratorio de datos de clientes de una empresa de telecomunicaciones.
## Objetivo
Este proyecto contiene datos de ConnectaTel, una empresa de telecomunicaciones, que analiza patrones de uso, comportamientos atípicos y segmentos de clientes para entender las necesidades tanto del cliente como la empresa y mejorar la experiencia del usuario.
## Datasets utilizados
Las fuentes de datos fueron proporcionados como parte del proyecto, se encuentran 3 archivos: 
1. plans.csv que contiene precio, minutos incluidos, GB incluídos.
2. users_latam.csv contiene información de clientes como edad, ciudad, fechas de registro, plan contratado.
3. usage.csv tiene información de uso como llamadas y mensajes.
## Etapas del análisis realizadas
El análisis inicia con la carga de archivos y exploración rápida de los datos, para continuar con:
1. Identificación de problemas de calidad de datos
2. Limpieza básica de datos.
3. Resumen estadístico de uso por usuario.
4. Visualización de distribuciones de uso, clientes y outliers.
5. Segmentación de Clientes.
6. Insight Ejecutivo para Stakeholders.
